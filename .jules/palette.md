## 2024-05-24 - [Skip to Content Link]
**Learning:** Standard navigation structures often create keyboard traps or repetitive tabbing. A "Skip to content" link is a critical, invisible pattern that drastically improves keyboard usability.
**Action:** Always verify if a site structure allows easy access to main content without tabbing through the entire navigation menu.

## 2024-05-24 - [Accessible Icon Toolbars]
**Learning:** Icon-only toolbars (like font size or theme toggles) are often invisible to screen readers. Adding `aria-label` provides necessary context, and `aria-live` on value displays (like "16px") ensures users know when their action has taken effect.
**Action:** When creating custom control widgets, always ensure every interactive element has an accessible name and that status changes are announced.
